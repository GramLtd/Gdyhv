# Post Bot — конструктор постов для Telegram

Бот собирает и отправляет посты с форматированием, ссылками в тексте, премиум-эмодзи и кнопками.

## Возможности

- **Текст**: форматируешь прямо в Telegram (жирный, курсив, спойлер, цитата, моноширинный,
  **ссылка внутри слова**) или присылаешь HTML. Премиум-эмодзи сохраняются.
  «🧾 Текст как HTML-код» выдаёт текущий текст кодом: копируешь, правишь, присылаешь обратно.
- **Медиа**: фото, видео, GIF, файл с подписью. Пересланный пост импортируется вместе с кнопками-ссылками.
- **Кнопки**: ссылка, Mini App, всплывающее окно, уведомление сверху, копирование текста,
  **запрос звёзд** (оплата Telegram Stars), **запрос подарка Telegram**,
  inline-запрос (в этом чате, в другом, с выбором чата) и 25 готовых ссылок на разделы Telegram
  (профиль, ЛС с текстом, добавить бота в группу/канал, стикеры, эмодзи-паки, буст, настройки,
  Premium, Stars, папки, конфиденциальность…).
  У каждой кнопки: цвет (синяя/зелёная/красная), премиум-эмодзи иконка, порядок и ряды.
- **Шаблоны**: сохранить, обновить, сохранить как новый, переименовать, удалить, открыть в редакторе.
- **Отправка**: сюда, в канал или группу (бот должен быть админом), через inline (`@бот название`).
- **Отправленные посты** можно потом изменить (текст, кнопки, медиа) или удалить.
- `/emoji` показывает ID премиум-эмодзи и HTML-код для них.

## Смена поста по кнопке

Тип кнопки **«🔄 Сменить пост»**: по нажатию бот заменяет текст, медиа и кнопки сообщения
на содержимое выбранного шаблона. В том шаблоне могут быть свои такие кнопки — получаются
цепочки экранов, меню, квизы, кнопка «назад». Шаблон без текста и медиа меняет только кнопки.
В каналах и группах пост меняется у всех зрителей.

## Переменные и быстрое заполнение

В тексте, кнопках, ссылках и всплывающих окнах шаблона: `{link}`, `{link_text}`
(`t.me/nft/PlushPepe-1234` → «Plush Pepe #1234»), `{link_name}`, `{link_num}`, `{link_slug}`,
`{1}`…`{9}`. Слово-ссылка: адрес `https://link.com` заменится на настоящую ссылку.

Заполнить: inline `@бот название ссылка 500 текст` (с пробелами внутри — через `|`)
или «✍️ Заполнить переменные» в шаблоне.

## Платный доступ и магазин шаблонов

Нужен `ADMIN_IDS` в `.env` (ты — владелец). Команда **/admin**:
- **Платный редактор**: вкл/выкл, цена в ⭐ и срок в днях. Подписчики получают полный редактор.
- **Шаблоны для пользователей**: публикация любого своего шаблона с доступом
  🆓 бесплатно / ⭐ по подписке / 💰 за N ⭐ навсегда, название, описание и **свои вопросы**
  для каждой переменной («🔗 Ссылка на NFT», «💰 Цена»…).
- У каждого шаблона своё меню и прямая ссылка `t.me/бот?start=t_ID`: пользователь отвечает
  на вопросы и получает готовый пост — переслать, отправить в свой канал или через inline.
- Выдать/забрать доступ вручную, статистика.

Пользователи без доступа видят только **/menu** — магазин шаблонов и покупку подписки.
Магазин: `t.me/бот?start=shop`.

## Таймер

«⏱ Таймер» в редакторе + `{timer}` в тексте.
- **Живой**: бот раз в минуту обновляет пост (`2 д 05:13`), по окончании пишет твой текст.
  Работает в постах, отправленных ботом.
- **Telegram**: клиент сам показывает «через 3 часа» у каждого зрителя, бот пост не трогает.
Часовой пояс для ввода времени — `TZ_NAME` в `.env` (по умолчанию Europe/Moscow).

## Звёзды и подарки

- **⭐ Запрос звёзд**: кнопка открывает окно оплаты Stars на заданную сумму (1–10000).
  Звёзды приходят на баланс бота, автору поста приходит уведомление.
- **🎁 Запрос подарка**: выбираешь подарок из каталога Telegram и получателя (себя, канал или
  пользователя). Нажавший кнопку платит стоимость подарка звёздами, бот сразу отправляет
  подарок получателю с подписью. Если отправить не удалось, звёзды автоматически возвращаются.
- Кнопки — обычные ссылки на счёт, поэтому работают везде: в каналах, группах, через inline.
- Получатель-пользователь должен хотя бы раз написать боту.

## Запуск

```bash
cd postbot
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впиши BOT_TOKEN, по желанию ADMIN_IDS
python bot.py
```

В @BotFather включи inline-режим (`/setinline`), иначе отправка через `@бот` работать не будет.

## Ограничения Telegram

- **Премиум-эмодзи в тексте, иконки и цвета кнопок** бот может отправлять, только если у бота
  есть username, купленный на Fragment. Без него Telegram покажет обычные эмодзи. Бот это
  видит и показывает пост без иконок с предупреждением.
- Кнопка **Mini App** (`web_app`) работает только в личке с ботом. Для каналов используй
  ссылку `t.me/bot/app` (пресет «📱 Mini App по ссылке»).
- Ссылки `tg://…` открываются не во всех клиентах.
- Окна и уведомления у кнопок работают, пока бот запущен.
- Подпись к медиа — до 1024 символов, текст — до 4096.
