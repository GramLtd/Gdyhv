# Post Bot — конструктор постов для Telegram

Бот собирает и отправляет посты с форматированием, ссылками в тексте, премиум-эмодзи и кнопками.

## Возможности

- **Текст**: форматируешь прямо в Telegram (жирный, курсив, спойлер, цитата, моноширинный,
  **ссылка внутри слова**) или присылаешь HTML. Премиум-эмодзи сохраняются.
  «🧾 Текст как HTML-код» выдаёт текущий текст кодом: копируешь, правишь, присылаешь обратно.
- **Медиа**: фото, видео, GIF, файл с подписью. Пересланный пост импортируется вместе с кнопками-ссылками.
- **Кнопки**: ссылка, Mini App, всплывающее окно, уведомление сверху, копирование текста,
  inline-запрос (в этом чате, в другом, с выбором чата) и 25 готовых ссылок на разделы Telegram
  (профиль, ЛС с текстом, добавить бота в группу/канал, стикеры, эмодзи-паки, буст, настройки,
  Premium, Stars, папки, конфиденциальность…).
  У каждой кнопки: цвет (синяя/зелёная/красная), премиум-эмодзи иконка, порядок и ряды.
- **Шаблоны**: сохранить, обновить, сохранить как новый, переименовать, удалить, открыть в редакторе.
- **Отправка**: сюда, в канал или группу (бот должен быть админом), через inline (`@бот название`).
- **Отправленные посты** можно потом изменить (текст, кнопки, медиа) или удалить.
- `/emoji` показывает ID премиум-эмодзи и HTML-код для них.

## Запуск

```bash
cd postbot
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впиши BOT_TOKEN, по желанию ADMIN_IDS
python bot.py
```

В @BotFather включи inline-режим (`/setinline`), иначе отправка через `@бот` работать не будет.

## Ограничения Telegram

- **Премиум-эмодзи в тексте, иконки и цвета кнопок** бот может отправлять, только если у бота
  есть username, купленный на Fragment. Без него Telegram покажет обычные эмодзи. Бот это
  видит и показывает пост без иконок с предупреждением.
- Кнопка **Mini App** (`web_app`) работает только в личке с ботом. Для каналов используй
  ссылку `t.me/bot/app` (пресет «📱 Mini App по ссылке»).
- Ссылки `tg://…` открываются не во всех клиентах.
- Окна и уведомления у кнопок работают, пока бот запущен.
- Подпись к медиа — до 1024 символов, текст — до 4096.
