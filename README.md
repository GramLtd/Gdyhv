# XMR Miner — Telegram-бот + Mini App про майнинг Monero

Игровой «майнинг» Monero (RandomX, KH/s): ферма копит XMR, игрок забирает, улучшает уровень,
зовёт друзей, выполняет задания и выводит XMR на свой кошелёк.

## Возможности
- **Пополнение звёздами** — пакеты 100/500/1000/2500 Stars, курс XMR за ⭐ задаётся в админке.
- **Пополнение в TON** — перевод на `TON_WALLET` с комментарием `XMR<id>`; бот опрашивает toncenter
  каждые 20 с и зачисляет XMR по курсу из админки (защита от двойного зачисления по хешу транзакции).
- **Магазин за Stars** — бусты ×2/×3, уровни, хранилище, скины кулера.
- **Вывод XMR** — проверка адреса (стандартный `4…`, сабадрес `8…`, интегрированный) с контрольной суммой
  Keccak; заявки обрабатываются вручную в админке, ссылка на транзакцию в xmrchain.net.
- Рефералы, ежедневный бонус, задания рекламодателей, рассылка, бан, возврат Stars.

## Запуск
```bash
cp .env.example .env   # BOT_TOKEN, WEBAPP_URL, TON_WALLET, ADMIN_IDS
pip install -r requirements.txt
python main.py
```
Деплой на Ubuntu: `sudo bash deploy/install.sh your-domain.com`.
